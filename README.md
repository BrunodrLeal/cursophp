# 🐘 Estudos de PHP

Repositório dedicado aos meus estudos e à evolução prática na linguagem **PHP**, explorando conceitos fundamentais de programação e desenvolvimento web por meio de exercícios e pequenos projetos.

O objetivo é consolidar a lógica de programação, compreender o funcionamento da linguagem e desenvolver uma base sólida para atuar no desenvolvimento Back-End.

## 🎯 Objetivos

- Desenvolver o raciocínio lógico e a capacidade de resolução de problemas.
- Aprender e aplicar os principais recursos da linguagem PHP.
- Trabalhar com entrada, processamento e exibição de dados.
- Compreender a integração entre PHP e HTML.
- Evoluir gradualmente na construção de aplicações web.

## 📚 Conteúdos estudados

Durante o desenvolvimento dos exercícios, são explorados conceitos como:

- Variáveis e tipos de dados.
- Operadores aritméticos, relacionais e lógicos.
- Estruturas condicionais (`if`, `else` e `switch`).
- Estruturas de repetição (`for`, `while` e `foreach`).
- Manipulação de strings e números.
- Funções nativas do PHP.
- Arrays e manipulação de dados.
- Formulários HTML e recebimento de informações.
- Requisições HTTP (`GET`, `POST` e `REQUEST`).
- Validação e tratamento de entradas.
- Manipulação de datas e horários.

## 🛠️ Tecnologias e ferramentas

- **PHP** — Linguagem principal dos estudos.
- **HTML5** — Estruturação de páginas e formulários.
- **Visual Studio Code** — Editor de código.
- **Git e GitHub** — Versionamento e compartilhamento dos projetos.

## ▶️ Como executar os exercícios

1. Faça o download ou clone este repositório:

   ```bash
   git clone https://github.com/BrunodrLeal/cursophp.git
   ```

2. Abra a pasta do projeto no Visual Studio Code.

3. Certifique-se de ter o PHP instalado.

4. No terminal, acesse a pasta do exercício que deseja executar e inicie o servidor local:

   ```bash
   php -S localhost:8000
   ```

5. Acesse no navegador:

   ```text
   http://localhost:8000
   ```
